# 数据结构练习

> 路线：链表 → 顺序表 → 栈/队列 → 哈希表 → 树 → 图 → 排序 → 查找/字符串 → 算法技巧
>
> **打卡规则**
> - 一个 `.c` 文件 = 一个任务，任务内部按函数拆成小项；
> - 每完成一小项就勾选，一个任务全部勾完才算完成；
> - 每个任务要求能独立编译运行：`gcc xxx.c -o xxx`，`main` 里写自测用例；
> - 完成时更新：勾选 + 填日期 + 一句话备注（踩坑/心得）；
> - 攒几个任务就 `git add . && git commit -m "..." && git push` 同步到 gitcode。
